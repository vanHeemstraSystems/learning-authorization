# Learning Authorization

## Authorization Models & Access Control
CISSP Domain: Domain 3 - Security Architecture and Engineering, Domain 5 - IAM

### Learning Objectives:
	•	Understand different access control models
	•	Learn Role-Based Access Control (RBAC) design
	•	Explore Attribute-Based Access Control (ABAC)

### Study Topics:
	•	Discretionary Access Control (DAC)
	•	Mandatory Access Control (MAC)
	•	Role-Based Access Control (RBAC)
	•	Attribute-Based Access Control (ABAC)
	•	Rule-Based Access Control
	•	Access control matrices and capability tables

### Assignment:
Design a complete RBAC model for a healthcare organization including roles, permissions, and inheritance hierarchies. Then create an ABAC policy set for the same organization covering patient data access scenarios.
